# PLAN — Синхронный переводчик с AR

## Этап 0. Инфраструктура
- [x] Создать `PLAN.md` и структуру пакетов
- [ ] `pyproject.toml` с зависимостями (sounddevice, numpy, faster-whisper, httpx, edge-tts, fastapi, uvicorn, opencv-python, pytest)
- [ ] `translator/config.py` — конфиг через env-переменные
- [ ] `translator/logging_setup.py` — единая настройка логирования

## Этап 1. MVP: базовый перевод речи
- [x] **Шаг 1.1.** Захват аудио с микрофона → WAV (`translator/audio/recorder.py`) + тест
- [ ] **Шаг 1.2.** STT через `faster-whisper` (`translator/stt/whisper_stt.py`) + тест с моком
- [ ] **Шаг 1.3.** Перевод через DeepSeek API (`translator/translate/deepseek.py`) + тест с моком httpx
- [ ] **Шаг 1.4.** TTS через `edge-tts` (`translator/tts/edge_tts.py`) + тест
- [ ] **Шаг 1.5.** CLI-пайплайн: запись → STT → перевод → TTS/текст
- [ ] **Шаг 1.6.** История реплик в SQLite (`translator/history/store.py`) + тест

## Этап 2. Групповой режим
- [ ] WebSocket-сервер на FastAPI (`translator/net/server.py`)
- [ ] Модель сессии: участники, роли (speaker/listener), языки
- [ ] Маршрутизация реплик: голос говорящего → перевод на язык каждого слушателя
- [ ] Вопросы из группы → перевод на язык основного говорящего
- [ ] История с авторством и временем

## Этап 3. AR-режим
- [ ] Захват кадра с камеры (OpenCV)
- [ ] Распознавание текста (OCR) и/или простых объектов
- [ ] Поиск/описание объекта и перевод на язык пользователя
- [ ] Вывод поверх кадра (overlay)

## Правила
- Один шаг = одна маленькая функция + тест.
- После каждого шага обновляем этот файл.
- Если шаг дублируется — меняем подход.
